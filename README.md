# ai-casher-bruh: арбитражный сканер с сигналами в Telegram

Бот сравнивает цены монет на нескольких криптобиржах (Bybit, OKX, Gate, MEXC, KuCoin, HTX, Bitget)
и присылает в Telegram сообщение, когда монету можно **купить на одной бирже дешевле,
чем продать на другой**, причём с учётом торговых комиссий и глубины стакана.

```
🟢 PEPE/USDT  +1.19% чистыми (спред 1.39%)
   Купить: MEXC Global по 0.0000101
   Продать: Gate по 0.00001024
   Объём 24ч: $2.0M / $800k
   Стакан на $100: +$1.13 (+1.13%)
```

> **Бот ничего не покупает и не продаёт сам.** Он использует только публичные данные бирж,
> поэтому API-ключи не нужны и твои деньги в безопасности. Решение о сделке принимаешь ты.

---

## ⚠️ Прочитай до того, как нести деньги

Арбитраж — реальная схема, но не «бесплатные деньги». Сигнал ещё не означает прибыль:

1. **Комиссия за вывод.** Бот учитывает торговые комиссии, но не учитывает плату за перевод монеты
   с одной биржи на другую. На суммах в $100 она легко съедает всю прибыль.
2. **Время перевода.** Пока монета идёт с биржи на биржу (от минут до часов), цена может уйти.
   Профи держат деньги на обеих биржах заранее и переводов в момент сделки не делают.
3. **Закрытый ввод/вывод.** Большие спреды часто держатся именно потому, что биржа закрыла
   депозиты или выводы этой монеты. Проверяй это на сайте обеих бирж.
4. **Разные монеты с одинаковым тикером.** Иногда под одним названием на разных биржах торгуются разные
   токены. Сверь контракт и сеть. Спреды выше `MAX_PROFIT_PERCENT` бот отсекает как раз по этой причине.
5. **Начинай с маленьких сумм** и сначала просто понаблюдай за сигналами пару дней.

## Установка с нуля (пошагово)

### Шаг 1. Установи Python

* **Windows:** скачай Python 3.10 или новее с [python.org](https://www.python.org/downloads/).
  При установке **обязательно поставь галочку «Add Python to PATH»**.
* **macOS:** `brew install python` или установщик с python.org.
* **Linux:** обычно Python уже есть; проверь командой `python3 --version`.

Проверка: открой терминал (на Windows это «Командная строка» или PowerShell) и введи:

```bash
python --version
```

Должно появиться что-то вроде `Python 3.12.x`. На macOS/Linux вместо `python` пиши `python3`.

### Шаг 2. Скачай проект

Если установлен git:

```bash
git clone https://github.com/Ski1los/ai-casher-bruh.git
cd ai-casher-bruh
```

Если git нет: на странице репозитория нажми **Code → Download ZIP**, распакуй архив
и открой терминал в этой папке.

### Шаг 3. Создай виртуальное окружение и поставь библиотеки

Виртуальное окружение — это отдельная «коробка» для библиотек проекта, чтобы они не смешивались с системными.

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Когда окружение активно, в начале строки терминала появится `(.venv)`. Команду `activate`
нужно повторять каждый раз, когда открываешь новый терминал.

### Шаг 4. Проверь, что биржи отвечают (без Telegram)

```bash
python scan_once.py
```

Ты увидишь, какие биржи ответили, и список найденных связок. Если какая-то биржа пишет ошибку
(например, недоступна в твоём регионе), просто убери её из списка `EXCHANGES` на шаге 6.

### Шаг 5. Создай Telegram-бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot`, придумай имя и username (он должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Это пароль от бота, никому его не показывай.

### Шаг 6. Настрой файл `.env`

Скопируй шаблон:

* Windows: `copy .env.example .env`
* macOS/Linux: `cp .env.example .env`

Открой `.env` в любом текстовом редакторе (Блокнот подойдёт) и вставь токен:

```
TELEGRAM_BOT_TOKEN=1234567890:AAH...
```

Остальные параметры можно пока не трогать: в файле есть пояснение к каждому.

### Шаг 7. Запусти бота

```bash
python main.py
```

Открой своего бота в Telegram и нажми **Start**. Затем:

* `/scan` — разовое сканирование;
* `/auto_on` — бот будет сам писать при появлении новых связок.

Остановить бота: `Ctrl + C` в терминале.

### Шаг 8. Закрой бота от чужих

Отправь боту `/myid`, скопируй число и впиши его в `.env`:

```
ALLOWED_USER_IDS=123456789
```

Перезапусти бота. Теперь он будет отвечать только тебе.

## Команды бота

| Команда | Что делает |
|---|---|
| `/scan` | Просканировать биржи прямо сейчас |
| `/auto_on` / `/auto_off` | Включить / выключить автосигналы в этом чате |
| `/status` | Когда был последний скан и какие биржи не ответили |
| `/settings` | Показать настройки |
| `/set имя значение` | Изменить настройку на лету, например `/set min_profit 1` |
| `/myid` | Показать твой Telegram ID |

Что можно менять через `/set`: `min_profit`, `max_profit`, `min_volume`, `amount`, `interval`, `cooldown`.
Изменения через `/set` действуют до перезапуска. Чтобы сохранить их навсегда, поменяй значения в `.env`.

## Как это работает

```
каждые 60 с ─► забираем все цены со всех бирж (одним запросом на биржу)
            ─► для каждой монеты ищем биржу, где купить дешевле всего (ask),
               и биржу, где продать дороже всего (bid)
            ─► вычитаем торговые комиссии обеих бирж
            ─► отсекаем неликвид (маленький объём) и подозрительно большие спреды
            ─► для 10 лучших связок смотрим стаканы: сколько реально получишь на $100
            ─► шлём в Telegram новые связки (одну и ту же не чаще раза в 30 минут)
```

### Структура проекта

```
main.py              запуск Telegram-бота
scan_once.py         одно сканирование в консоли (для проверки)
bot/config.py        чтение настроек из .env
bot/scanner.py       логика поиска арбитража (работает с биржами через ccxt)
bot/telegram_bot.py  команды Telegram и автосигналы
tests/               автотесты: python -m pytest
```

## Что можно добавить дальше

* **Проверка ввода/вывода и сетей монеты.** Для большинства бирж нужны API-ключи (только на чтение).
* **Учёт комиссии за вывод** при расчёте прибыли.
* **Треугольный арбитраж** внутри одной биржи (USDT → BTC → ETH → USDT), без переводов между биржами.
* **Работа 24/7 на VPS-сервере**, чтобы не держать компьютер включённым.
* **Полуавтоматическая торговля** с подтверждением кнопкой в Telegram. Только после того,
  как ты убедишься, что сигналы действительно прибыльные.
