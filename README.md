# ai-casher-bruh: арбитражный сканер, демо-счета и торговля из Telegram

Бот работает с двумя криптобиржами, **Bybit** и **BingX** (на них есть аккаунт), и ищет две вещи:

* **Межбиржевой арбитраж**: монету можно купить на одной бирже дешевле, чем продать на другой.
* **Треугольный арбитраж**: цикл из трёх обменов внутри одной биржи (USDT → A → B → USDT),
  после которого USDT становится больше. Переводов между биржами нет, поэтому это единственная
  стратегия, где у маленькой суммы вообще есть шанс.

Каждая находка проверяется по реальному стакану заявок. Поверх этого работают **демо-счета**:
бот сам «торгует» виртуальными $5, $50 и $500 по обеим стратегиям и каждый день присылает отчёт.
Так видно, есть ли деньги на самом деле, без единого вложенного рубля.

Поверх всего работает **ИИ-помощник** 🧠 (бесплатный, без карты). Он видит все цифры бота:
комиссии каждой биржи, результаты сканов, сделки и отказы демо-счетов. Он объясняет, что съедает прибыль,
отвечает на вопросы обычным текстом и предлагает настройки, которые применяются только твоей кнопкой.
Есть и **анализ без ИИ** (`/analysis`): точная математика комиссий и безубыточности.

```
🔺 USDT → PEPE → BTC → USDT  +0.229% чистыми
   Биржа: Bybit
   1) купить PEPE/USDT по 0.0000101
   2) продать PEPE/BTC по 0.0000000001043
   3) продать BTC/USDT по 97350
   Стакан на $100: +$0.215 (+0.215%)
```

**Торговля прямо из бота** 💼: покупка и продажа кнопками и командами, лимитные ордера, кнопка
«⚡ Исполнить» под треугольниками, автоторговля и ИИ-трейдер, которому можно написать
«купи эфира на 5$ на байбите». Без API-ключа бот только сканирует и ведёт демо.
С ключом он сначала работает в **тестовом режиме**: всё считает по реальному балансу и стаканам, но ордера не отправляет.
Подробно в разделе [💼 Торговля](#-торговля-из-бота).

**📱 Приложение внутри Telegram.** Кнопка **App** слева от поля ввода открывает полноценное приложение:
график баланса, свечные графики любой монеты, покупка и продажа в два касания, сигналы со шкалой прибыли,
демо-счета с кривыми доходности, портфель с диаграммой и ИИ-чат. Тёмная и светлая тема, как в Telegram,
вибрация на кнопках. Подробно в разделе [📱 Приложение](#-приложение-mini-app).

## ⚠️ Прочитай до того, как нести деньги

Арбитраж — реальная схема, но не «бесплатные деньги». Сигнал ещё не означает прибыль:

1. **Комиссия за вывод.** Сигналы учитывают торговые комиссии, а плату за перевод монеты
   между биржами учитывают демо-счета и `/analysis`. На маленьких суммах она легко съедает всю прибыль.
2. **Время перевода.** Пока монета идёт с биржи на биржу (от минут до часов), цена может уйти.
   Профи держат деньги на обеих биржах заранее и переводов в момент сделки не делают.
3. **Закрытый ввод/вывод.** Большие спреды часто держатся именно потому, что биржа закрыла
   депозиты или выводы этой монеты. Проверяй это на сайте обеих бирж.
4. **Разные монеты с одинаковым тикером.** Иногда под одним названием на разных биржах торгуются разные
   токены. Сверь контракт и сеть. Спреды выше `MAX_PROFIT_PERCENT` бот отсекает как раз по этой причине.
5. **Начинай с маленьких сумм** и сначала просто понаблюдай за сигналами пару дней.

## ☁️ Запуск в облаке бесплатно, только с телефона

Бот работает на бесплатном хостинге [Render](https://render.com): без карты, сервер во Франкфурте,
управление через Telegram. Компьютер не нужен.

### 1. Telegram ID владельца уже вписан
В `render.yaml` уже стоит `ALLOWED_USER_IDS=6069246522`: бот будет отвечать только этому аккаунту,
ему же пойдут отчёты и бэкапы. Если нужен другой владелец, поменяй число в `render.yaml`
или в настройках сервиса на Render (свой ID покажет [@userinfobot](https://t.me/userinfobot)).

### 2. Разверни бота в один клик
Открой на телефоне ссылку:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Ski1los/ai-casher-bruh)

`https://render.com/deploy?repo=https://github.com/Ski1los/ai-casher-bruh`

1. Нажми **Sign in with GitHub** (вход через твой GitHub).
2. Render покажет сервис `ai-casher-bot` и поля для секретов. Заполни сразу:
   * `TELEGRAM_BOT_TOKEN` — токен от @BotFather (обязательно);
   * `BYBIT_API_KEY` / `BYBIT_API_SECRET`, `BINGX_API_KEY` / `BINGX_API_SECRET` — ключи бирж
     (права: только чтение + спот-торговля, **без вывода**, без IP);
   * `AI_API_KEY` — ключ Groq (по желанию). Остальные поля можно оставить пустыми.
3. Нажми **Deploy Blueprint** (или **Apply**).
4. Подожди 3–5 минут, пока статус станет **Live**. Бот сам напишет «👋 Бот установлен и работает».
   Если не написал — открой адрес сервиса с `/status` на конце (`https://…onrender.com/status`):
   там видно, что не так. **Сервис должен быть один**: два сервиса с одним токеном мешают друг другу.

### 3. Пользуйся
Открой своего бота в Telegram → **Start** → **🚀 С чего начать** (или `/setup`): бот проверит ключи, деньги
на торговом счёте и стратегию и кнопкой предложит следующий шаг. Демо-счета: `/demo_start`. Всё: запустятся 6 демо-счетов
($5, $50, $500 × две стратегии), сделки будут приходить сообщениями, а каждый день в 9:00 по Москве придёт отчёт.

Открой приложение: кнопка **App** слева от поля ввода или команда `/app`.
Оно появляется само, потому что Render выдаёт адрес с https.

### 4. Подключи ИИ-помощника (бесплатно, 3 минуты, по желанию)
Без ИИ бот работает полностью, но с ним можно спрашивать обычным текстом и получать разбор.
1. Открой [console.groq.com/keys](https://console.groq.com/keys) и войди через Google. Карта не нужна.
2. **Create API Key** → любое имя → скопируй ключ (начинается с `gsk_`).
3. Render → сервис `ai-casher-bot` → **Environment** → **Add Environment Variable**:
   Key `AI_API_KEY`, Value — ключ → **Save Changes**. Бот перезапустится сам примерно за минуту.
4. В Telegram отправь `/ai`: придёт разбор. Дальше можно просто писать вопросы.

Ключ — как пароль: никому не показывай и не присылай в чат (даже этому боту).
Вместо Groq подойдёт ключ [OpenRouter](https://openrouter.ai/keys) (`sk-or-…`) или
[Google AI Studio](https://aistudio.google.com/apikey) (`AQ.…` — новый формат, или старый `AIza…`): бот сам поймёт по ключу, чей он.
Можно подключить **сразу несколько ИИ** — тогда работает 🧠 консилиум (`/council`), см. раздел «Больше ИИ» ниже.

**Обновления.** Render сам обновляет сервис только если он привязан к подключённому аккаунту GitHub.
Сервис, созданный кнопкой по публичной ссылке, обновляется вручную — поэтому бот сам следит за версией:
- узнать версию и обновиться: команда `/update` в боте (версия видна и в `/status`);
- обновить вручную: Render → `ai-casher-bot` → **Manual Deploy → Deploy latest commit**;
- **чтобы бот обновлялся сам** (один раз): Render → `ai-casher-bot` → **Settings → Deploy Hook** → скопировать →
  **Environment → Add** `RENDER_DEPLOY_HOOK_URL` = скопированное → **Save Changes**. Ссылка секретная, никому не присылай.

Данные (демо-счета, настройки) при обновлении сохраняются: бот восстановит их из закреплённого бэкапа.

### 5. Подключи биржу для торговли (по желанию)
Инструкция по шагам есть в самом боте: отправь `/keys`. Коротко:
1. На **сайте** биржи (в браузере телефона включи «версию для ПК»): **Профиль → API → Создать ключ** (системный, HMAC).
2. Права: **чтение + спотовая торговля** — этого хватает для торговли. Право **Withdraw** включай, только если хочешь
   🔁 переводы между биржами (`/transfer`), и тогда обязательно с привязкой к IP и адресной книгой (раздел v42 ниже).
3. Render → `ai-casher-bot` → **Environment**: `BYBIT_API_KEY` и `BYBIT_API_SECRET`,
   `BINGX_API_KEY` и `BINGX_API_SECRET` → **Save Changes**.
4. В Telegram: `/doctor` проверит всё сразу, `/balance` покажет баланс, `/trade` откроет панель.

Других бирж в боте нет: каждая лишняя биржа съедала память бесплатного сервера и время скана,
а торговать без аккаунта на ней всё равно нельзя. Если в Render остались старые ключи
(`OKX_API_KEY` и т. п.), их можно удалить: `/doctor` подскажет.

| | Bybit | BingX |
|---|---|---|
| Что нужно в Render | `BYBIT_API_KEY`, `BYBIT_API_SECRET` | `BINGX_API_KEY`, `BINGX_API_SECRET` |
| Passphrase | не нужен | не нужен |
| Срок ключа без IP | ~3 месяца. Бот покажет дату в `/doctor` и напомнит за 2 недели | удаляется после 14 дней **без запросов**. Бот обращается каждые 15 минут, так что ключ живёт |
| Где лежат деньги для бота | счёт **Unified Trading** | счёт **Spot** |
| Если деньги на Funding / Fund | `/doctor` подскажет, сколько там и куда перевести (перевод внутри биржи бесплатный) | так же |
| Если биржа не пускает сервер | `403 … block access from your country`: добавь `BYBIT_HOSTNAME=bytick.com` | — |

### Как это устроено и что важно знать
* **Сервер не засыпает.** Бесплатный Render усыпляет сервис через 15 минут без запросов,
  поэтому бот сам пингует свой адрес каждые 10 минут. 750 бесплатных часов в месяц
  хватает ровно на один сервис 24/7, так что **не создавай второй бесплатный сервис в этом аккаунте**.
* **Данные не теряются.** На бесплатном тарифе файлы стираются при каждом перезапуске,
  поэтому бот хранит резервную копию (демо-счёт, подписки) файлом `bot_state.json`
  в **закреплённом сообщении** в чате с тобой. **Не удаляй и не открепляй его.** Бэкап работает,
  только если заполнен `ALLOWED_USER_IDS`.
* **Обновления ставятся сами.** Любое изменение кода в ветке `main` Render развернёт автоматически.
* **Не запускай бота одновременно и в облаке, и на компьютере**, иначе Telegram выдаст ошибку `Conflict`.
* **Память.** У бесплатного Render 512 МБ. После запуска бот занимает около 185 МБ (до v31 было ~235):
  из библиотеки бирж грузятся только Bybit и BingX, а не все ~110 бирж. Остальное бот держит под контролем:
  каждые 10 минут убирает устаревшие записи и возвращает память системе.
  `/clean` сделает это сразу и покажет, сколько занято; `/doctor` тоже показывает память.
* **Поменять токен или настройки:** Render → твой сервис → **Environment** → изменить → **Save**.
  Любой параметр из `.env.example` (например, `MIN_PROFIT_PERCENT`) можно добавить туда же.
* **Если после обновления бот ругается на биржи** (очень маловероятно): добавь в Environment `CCXT_FULL=1`,
  и бот загрузит библиотеку бирж целиком, как раньше. Памяти уйдёт на ~50 МБ больше.
* **Если токен утёк** (его видел кто-то чужой): в @BotFather `/revoke` → новый токен → вставь в Render.
* **Бот молчит:** Render → сервис → **Logs**, там будет написана причина.

## Запуск на компьютере (необязательно)

Для работы бота компьютер не нужен: всё живёт в Render. Если когда-нибудь захочешь запустить у себя:

```bash
git clone https://github.com/Ski1los/ai-casher-bruh.git && cd ai-casher-bruh
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env    # впиши TELEGRAM_BOT_TOKEN и ALLOWED_USER_IDS
python main.py
```

Не запускай одновременно с Render: Telegram отдаст ошибку `Conflict`. Проверка кода: `python -m pytest`.

## 🧠 ИИ-помощник

**Что он видит:** настройки, комиссии каждой биржи, безубыточность каждой стратегии, последний скан
(лучшие связки с проверкой стакана, платой за вывод и статусом ввода/вывода), статистику за сутки,
включая самый близкий к прибыли вариант, даже убыточный, и все демо-счета: сделки, «ожидали → вышло» и причины отказов.

**Что он делает:**
* `/ai` — разбор: есть ли сейчас шанс заработать, сколько съедают комиссии, что не работает и почему, что делать;
* отвечает на любые вопросы обычным текстом и помнит последние 3 вопроса в чате;
* разбирает сигналы кнопкой «🤖 Разбор ИИ»;
* добавляет своё мнение в ежедневный отчёт;
* предлагает настройки (`tri_min`, `min_profit` и т.д.) кнопками. **Сам ничего не меняет**;
* **ИИ-трейдер:** напиши «купи эфира на 5$ на байбите» или «продай весь PEPE на BingX», и он подготовит ордер.
  Ты увидишь предпросмотр с реальной ценой и комиссией и кнопку «Подтвердить». Без кнопки ничего не исполнится.
  ИИ видит балансы и журнал сделок, но не может включить реальный режим, автоторговлю или поднять лимиты.

**Честно об ограничениях:**
* ИИ не делает арбитраж прибыльным. Он объясняет цифры и помогает не терять деньги на заведомо убыточном.
* Модели иногда ошибаются. Поэтому ИИ получает только реальные цифры бота, его советы проходят проверку
  допустимых значений, а применяются только кнопкой. Точная математика без ИИ всегда доступна в `/analysis`.
* Бесплатные лимиты: у Groq около 1000 запросов в день, бот сам ограничивает себя до 300 (`AI_DAILY_LIMIT`).
  Если лимит провайдера исчерпан, бот переключится на запасной ключ (все ключи из раздела «Больше ИИ»
  можно задать одновременно) или скажет, сколько подождать.
* Модель выбирается автоматически из доступных у провайдера. Если провайдер уберёт модель, бот возьмёт другую.
  Свою модель можно задать в `AI_MODEL`.
* Провайдеру уходят только цифры бота (цены, комиссии, результаты демо). Токены, ключи и личные данные
  не отправляются. На бесплатном тарифе Gemini Google может использовать запросы для обучения моделей.

**Комиссии.** Бот берёт стандартные taker-ставки бирж из ccxt. Если у твоего аккаунта ставка ниже
(VIP-уровень, оплата комиссии токеном биржи), задай её: `/fee bingx 0.04`. Это сразу учтётся в сигналах,
треугольниках, демо и анализе. Для постоянной настройки есть переменная `FEE_OVERRIDES=bybit:0.08,bingx:0.04`.

## 💼 Торговля из бота

**Режимы.**
* 🧪 **Тест** (по умолчанию). Бот берёт реальный баланс и свежий стакан, показывает, что получилось бы,
  и пишет это в журнал `/trades`. На биржу ничего не уходит. Можно тренироваться даже с пустым счётом.
* 🔴 **Реальный** (`/live` → «Да, торговать реально»). Ордера уходят на биржу. Вернуть тест: `/test`.

**Как торговать.**
* Командами: `/buy bybit ETH 5`, `/sell bybit ETH all`, `/limit bybit sell ETH all 4000`.
* Текстом ИИ: «купи эфира на 5 долларов на байбите».
* Кнопкой «⚡ Исполнить» под треугольником (если на этой бирже есть ключ): бот заново запрашивает три стакана
  и исполняет цикл, только если прибыль ещё есть.
* **Автоторговля** (`/autotrade on`): после каждого скана бот берёт лучший треугольник на биржах с ключами,
  если прибыль по стакану не ниже `auto_min` (по умолчанию 0.3%), и присылает отчёт о каждой сделке.

Любой ордер вручную или от ИИ проходит так: предпросмотр (цена, комиссия, сколько получишь) → кнопка
«Подтвердить» → перед отправкой бот ещё раз смотрит стакан и не отправляет сделку, если цена ушла хуже чем на `slippage`% или глубины недостаточно. Это проверка до отправки: рыночный ордер может исполниться по более плохой цене, и предел проскальзывания не гарантирован.

**Защита.**
| Что | По умолчанию | Как поменять |
|---|---|---|
| Максимум на одну покупку или цикл | $10 | `/set max_trade 20` |
| Убыток за сутки, после которого автоторговля встаёт на паузу | $2 | `/set daily_loss 5` |
| Максимум реальных сделок за сутки | 30 | `/set daily_trades 50` |
| Минимальная прибыль цикла для автоторговли | 0.3% | `/set auto_min 0.5` |
| Допустимое ухудшение цены перед ордером | 1% | `/set slippage 0.5` |

* Торговать может только владелец (первый ID в `ALLOWED_USER_IDS`). Каждая кнопка подтверждения
  срабатывает один раз и живёт 5 минут.
* Если цикл сорвался на втором или третьем шаге, бот сразу продаёт застрявшую монету обратно в USDT
  и пишет, что произошло.
* `/stop` выключает всё и отменяет открытые ордера. Монеты на балансе он не продаёт.
* Ключи хранятся только в настройках Render, их нет ни в коде, ни в бэкапе, ни в запросах к ИИ.
  Ключ без права вывода не позволит вывести деньги даже при утечке. Если для 🔁 переводов право вывода включено —
  ключ привязан к IP сервера, а биржа выводит только на адреса из твоей адресной книги.

**Честно о том, чего ждать.**
* Автоторговля не «печатает деньги». Треугольники с прибылью выше 0.3% появляются редко и живут доли секунды,
  а профессиональные боты стоят рядом с биржей. Наш сервер в облаке медленнее, поэтому часть сигналов к моменту
  исполнения исчезнет (бот тогда просто пропустит сделку), а часть сделок закроется в небольшой минус из-за проскальзывания.
* Сначала погоняй автоторговлю в тесте день-два и посмотри `/trades`. Если и в тесте результат около нуля,
  в реальности будет хуже.
* Межбиржевой арбитраж бот автоматически не исполняет: для этого нужны деньги заранее на обеих биржах и переводы.
* Ручные покупки, продажи и советы ИИ — это обычная спекуляция. Куда пойдёт цена, не знает никто, и ИИ тоже.
* Торгуй только той суммой, которую не жалко потерять полностью.

## ♾ Полный автомат: бот работает сам (`/autonomy`)

Включён сразу после обновления. Ничего нажимать не нужно — бот сам:

* **держит включённым всё, что учится без денег**: демо-арбитраж на $5, демо мемкоинов, копитрейдинг, учёба у
  трейдеров, тренировку, разведчика, эфиры (если есть ключ Gemini), лабораторию автопилота — **даже без ключа
  биржи** (на публичных свечах), автопилот в тесте (когда ключ есть). Выключил что-то руками — автомат включит
  обратно и скажет; чтобы выключить надолго, сначала выключи автомат;
* **сторож**: раз в 5 минут проверяет все циклы бота (сканер, автопилот, копитрейдинг, учёба, отчёты, обновления…)
  и перезапускает упавшие и зависшие; памяти стало много (>430 из 512 МБ) — убирает лишнее. Самого сторожа
  сторожит сканер;
* **«📊 Результат»** раз в 6 часов (3/6/12/24 или выкл): деньги за период, сколько новых сделок у каждого способа
  без денег и с каким итогом, что починил сам, есть ли новая версия и **следующий шаг**. Ночью (0–8) молчит, если
  ничего не произошло — не спамит (но раз в сутки скажет, что жив);
* **обновления** ставит сам, если один раз добавить `RENDER_DEPLOY_HOOK_URL` (кнопка «⬆️ Чтобы обновлялся сам»).

**Настоящие деньги — только с твоего разрешения** (кнопка «🔓 Разрешить деньги» + подтверждение). После этого
автомат сам переводит на деньги только то, что **доказало плюс без денег** в Профит-центре (✅: от 15 сделок, плюс
даже при невезении) и только при безопасных лимитах ($10 на сделку, $2 убытка в день):

| Способ | Что ещё нужно |
|---|---|
| 🤖 Автопилот на Bybit/BingX | рабочий ключ, треугольники выключены, одна копия бота |
| 💸 Мемкоины через Phantom | подключён кошелёк бота |

Начали терять — 🛡 Страж ставит паузу, автомат возвращает способ в тест (он продолжает учиться) и 3 дня не включает
снова. `/stop` снимает разрешение и останавливает всё; выключил способ руками — сам его больше не включит.
Честно: прошлый плюс не гарантирует будущий — клади на биржу и в кошелёк бота только сумму, которую не жалко.

## 💰 Профит-центр: что реально зарабатывает (`/profit`)

Одна таблица с результатами **всех** способов заработка: автопилот (настоящие и тестовые сделки), лаборатория,
копитрейдинг, мемкоины (демо и настоящие), тренировка на идеях трейдеров, арбитраж на демо.

- **Честный вердикт.** Для демо бот вычитает поправку на реальность: −0,1% за сделку на бирже и −2% на мемкоинах.
  «✅ доказан плюс» ставится только от 15 сделок и только если сделка в плюсе даже при невезении (средняя минус
  разброс). Остальные вердикты: 🟡 «в плюсе, но может быть везение», ⚪ около нуля, 🔴 доказанный минус, ⏳ мало данных.
  Бот судит по последним 40 сделкам.
- **План денег на $5 / $20 / $50 / $100** (или `/profit 30`). Если плюс доказан только без денег, в способ идёт
  минимальный ордер. После 8 настоящих сделок в плюсе доля считается по «четверти Келли» (формула размера ставки,
  урезанная в 4 раза), но не больше 60% денег в один способ. Остаток идёт в Bybit Earn под процент. Если ничего не
  доказало плюс, бот прямо так и говорит и прогноз роста не рисует.
- **🛡 Страж прибыли** (включён сразу). Если автопилот или мемкоины на **настоящих** деньгах доказанно теряют на
  последних 8–15 сделках, новые покупки ставятся на паузу на 3 дня. Открытые позиции бот ведёт дальше. Если демо
  копитрейдинга доказало минус, Страж выключает его сигналы, чтобы ты не повторял убыточные сделки руками. Всё
  возвращается одной кнопкой.
- **Сам пишет** в двух случаях. Первый: что-то доказало плюс, и можно пробовать настоящие деньги с минимума. Второй:
  настоящие сделки подтвердили плюс на 20 сделках, и можно увеличить сумму (не больше чем в 2 раза за раз).
- Кнопка «🧠 Совет ИИ» и ежедневный разбор ИИ (подойдёт и Gemini) опираются на эти цифры. Карточка 💰 есть в
  приложении.

Честно: прошлые сделки не гарантируют будущих, а демо обычно лучше реальности. Профит-центр не придумывает
доходность. Он делает так, чтобы деньги работали только там, где плюс доказан, и не горели там, где доказан минус.

## 🤖 Автопилот = режим $5 (`/autopilot`, `/scalp`)

**Одна кнопка — дальше бот торгует сам:** `/autopilot` в боте, кнопка «🤖 Включить автопилот» в `/setup`
или на главной в приложении. Включает режим $5 и «Монеты в дело». Реальные деньги — только после отдельного
подтверждения (до него всё работает в тесте). Состояние, позиции, монеты и стратегии: `/scalp` или плитка «Автопилот».

Треугольнику нужно три ордера, и Bybit требует от $5 на **каждый**, поэтому с $5 он не проходит.
В режиме $5 ордеров всего два:

1. Раз в 6 часов бот берёт свечи по 5 минут за ~3,5 дня по 13 крупным монетам и для **каждой** перебирает
   3 стратегии (комиссии учтены):
   - **Откат** — цена резко ушла ниже средней, RSI низкий;
   - **Отскок** — цена ушла под нижнюю полосу Боллинджера и развернулась вверх;
   - **Тренд** — в растущем рынке цена откатилась к короткой средней и пошла вверх.

   Вариант выбирается на первых 2/3 истории и **проверяется на последней трети, которую он «не видел»**
   (walk-forward). Монета годится, только если там не в минусе, а на всей истории — от 6 сделок и от +2%.
   Зачем так строго: на 300 случайных графиках (чистый шум, где заработать нельзя) простая проверка
   «в плюсе на истории» находила «прибыльную стратегию» в 41% случаев, эта — в 20%. Меньше самообмана —
   меньше сделок в минус. Таблица: `/scalp test`.
2. Ждёт сигнала своей стратегии. Обвал — не сигнал (фильтры −3% за час и −8% за сутки).
   **Тормоз рынка:** если BTC упал больше чем на 2% за час, новых покупок нет вообще.
3. Покупает на все свободные USDT (не больше `/set max_trade`) — прибыль сразу идёт в оборот.
4. Сразу ставит на бирже **лимитную продажу** на +0,6…1,3% после комиссий. Ордер стоит на бирже,
   даже если бот перезапустится.
5. Сутки без цели → продажа переставляется в безубыток. Стоп-лосс −6% срабатывает, только если позиция
   больше минимального ордера биржи (продать монеты дешевле $5 Bybit не даст).

Монеты с крупным шагом количества (например, BTC: шаг ≈ $0,09) бот с $5 не покупает: после округления
продажа не прошла бы минимум. Включается кнопкой в `/trade`, командой `/scalp on` или переключателем в приложении.
Режим $5 и автоторговля треугольниками взаимно выключают друг друга: им нужны одни и те же USDT.

**🪙 Монеты в дело** (включается автопилотом или кнопкой в `/scalp`). Если USDT на счёте меньше минимального
ордера, а монета (например, SOL) лежит без дела и стоит больше минимума, бот продаёт её по рынку в USDT и
дальше торгует этими деньгами. Только в реальном режиме; монету из открытой сделки и монеты в ордерах не трогает.
Выключил — монеты на счёте бот не трогает.

**🧪 Лаборатория (`/lab`, v20).** Проверка на истории может «подогнаться» под прошлое. Поэтому каждая монета
со своей стратегией дополнительно «торгует» без денег по живым свечам, по тем же правилам: вход по следующей
свече, цель, стоп −6%, через сутки безубыток. Если стратегия вживую в минусе (от 3 бумажных сделок, судим по
последним 20), реальные деньги на неё не идут. Монеты, которые вживую в плюсе, проверяются первыми. Лаборатория
работает, даже когда бот в сделке, и никогда не отправляет ордера.

**🧠 Самообучение (v21).** Лаборатория проверяет вживую **все 3 стратегии** каждой монеты, а не только ту, что
выбрала история. Если запасная стратегия вживую дала не меньше 6 сделок, в сумме ≥ +1,5% (то есть стоп-лоссы
перекрыты прибылью) и ≥ 60% сделок в плюс, а на истории по этой монете она не в минусе, — она получает ⭐ и
торгует за реальные деньги, даже если история выбрала другую стратегию или монета не прошла отбор.

- Проверка на 300 смоделированных графиках:
  - где заработать нельзя (чистый шум), ⭐-стратегии дали в будущем около нуля (+0,3%), то есть вреда нет;
  - где есть откаты, ⭐-стратегии дали +3,8% и 74% в плюс, а рабочих вариантов нашлось в 2,8 раза больше,
    чем только по истории: бот меньше простаивает.
- **Учится всегда:** даже когда автопилот выключен, лаборатория работает (без денег и ордеров), если есть ключ
  биржи. К моменту включения у бота уже будет опыт.
- **Не забывает:** Render стирает файлы при перезапуске, поэтому результаты лаборатории не реже раза
  в полчаса уходят в бэкап в Telegram и восстанавливаются после перезапуска.

**🛡 Щит (v20).** Бот не покупает:
- монеты, по которым Bybit объявил делистинг (45 дней);
- монеты из свежих (до 12 ч) новостей о взломе, эксплойте, иске, банкротстве, делистинге
  (BTC и ETH не блокируются: «биржу взломали, биткоин упал» — не про сам биткоин);
- монету в течение суток после её стоп-лосса;
- ничего на бирже в течение 12 часов после 2 убытков подряд (открытые продажи остаются).

Продажа вручную щит не включает. Всё, что сейчас под защитой, видно в `/scalp`, в приложении и в утреннем отчёте.

**Меньше запросов.** Сигнал меняется только при закрытии 5-минутной свечи, поэтому свечи для сигналов скачиваются
раз на свечу, а не каждые 30 секунд — меньше шанс упереться в лимиты биржи.

**Честно:** прибыль не гарантирована. На падающем рынке деньги могут надолго «зависнуть» в монете.

**Две копии бота.** Если в Render два сервиса с одним токеном, бот это замечает (Telegram отвечает «Conflict»),
ставит новые сделки на паузу и пишет, какой сервис удалить. Два сервиса ещё и тратят бесплатные 750 часов Render
вдвое быстрее.

## 🐋 Копитрейдинг кошельков Solana (`/copy`)

Идея: в мемкоинах есть кошельки, которые стабильно покупают растущие токены раньше толпы. Бот ищет такие кошельки,
следит за ними и **проверяет, можно ли на них заработать именно нам, с опозданием и комиссиями**. Только проверенные
попадают в сигналы.

1. **Ищет сам** (раз в 2 часа). Берёт токены, которые выросли на 50%+ и не оказались скамом (ликвидность от $30k,
   возраст 2–96 ч, есть продажи), и смотрит, кто их купил **в первые минуты**. Кошельки, которые встречаются
   в нескольких таких токенах, становятся кандидатами.
2. **Оценивает риск по истории** (последние 40 сделок): 🤖 бот-снайпер (сотни сделок в день — скопировать нельзя),
   ⚡ продаёт за минуты (не успеть), 📉 в минусе — сразу на кладбище. Подходящие проверяются копиями.
3. **Копирует без денег.** Увидел покупку — «покупает» на $5 по цене, которую реально получил бы ты: цена
   DexScreener в момент, когда бот её заметил, плюс проскальзывание 1% и комиссия Phantom 0,85% в обе стороны.
   Выход: кошелёк продал, стоп −40%, пул слили (считается как −90%), 48 часов.
4. **Фильтр рисков.** Ликвидность, RugCheck, возраст токена, переплата к цене кошелька, рост за час.
   Копии, которые фильтр отсеял, тоже считаются: так видно, помогает ли фильтр.
5. **Учится на ошибках.** У каждой убыточной копии есть диагноз: поздний вход, мало ликвидности, кошелёк продал за минуты,
   слив пула… После 20 копий бот сам двигает пороги фильтра, если на истории это дало бы хотя бы на 5% больше.
   Каждое изменение записывается уроком («🧠 Чему научился»).
6. **Эволюционирует.** ⭐ — от 5 копий и в среднем от +2% на копию (с поправкой на везение). 🔴 — 4 убытка подряд или
   −40% суммарно: бот выгоняет кошелёк и ищет замену. Если кошелёк неделю молчит, бот его убирает.
7. **Сигналы.** Покупки ⭐-кошельков, прошедшие фильтр, приходят в чат с кнопкой «Купить в Phantom» (Jupiter),
   продажи — с предупреждением. Не больше 6 в час, повтор по токену не раньше чем через 6 ч.

Свой кошелёк (например из GMGN или Axiom): `/copy add АДРЕС Имя`, убрать — `/copy del АДРЕС`.
В приложении: карточка «🐋 Копитрейдинг» на главной.

**Честно:**
- с твоего основного Phantom бот не торгует никогда. Чтобы он торговал сам, нужен отдельный кошелёк «Бот» —
  см. следующий раздел (`/meme`);
- прошлые успехи кошелька не гарантируют будущих. Большинство мемкоинов падает почти до нуля;
- копия всегда хуже оригинала: кошелёк покупает раньше и дешевле. Поэтому бот и проверяет копиями, а не верит
  истории кошелька;
- публичный узел Solana может отвечать «подождите». Бесплатный ключ [Helius](https://www.helius.dev) →
  переменная `SOLANA_RPC_URL` в Render сделает всё быстрее.

## 💸 Бот сам торгует мемкоинами (`/meme`)

Бот покупает и продаёт мемкоины Solana **сам**, вслед за ⭐-кошельками из копитрейдинга, через Jupiter
(лучший маршрут по всем DEX, Jupiter сам доставляет транзакцию в сеть). Можно и вручную: `/meme buy АДРЕС_ТОКЕНА 2`.

### 🧪 Демо-счёт — пока кошелёк не подключён и не пополнен

Ничего настраивать не нужно: при первом запуске бот открывает **демо-счёт на $10 виртуальных SOL** и включает
копитрейдинг (без денег). Дальше он торгует по **тем же правилам**, что и реальными деньгами: те же кошельки, риск-фильтр,
проверка «туда-обратно» по **настоящей котировке Jupiter**, лимиты, стоп, продажа вслед за кошельком. Сделки приходят
сообщениями «🧪 Демо: купил / продал», итог — в `/meme` и в приложении (🐋 → «🧪 Демо-счёт»).

- Демо копирует ⭐, 👀-кошельки с хорошей историей и 🔍 новые кошельки (с v44) — чтобы набирать опыт с первых часов,
  а не ждать днями первую ⭐. Каждую группу бот бросает, как только её копии докажут убыток (от 12–15 копий).
  Настоящий счёт копирует только ⭐ (👀 — по кнопке).
- Кошельки бот ищет каждые 20 минут, пока их меньше 5 (потом раз в 2 часа): ранние покупатели выросших токенов
  (DexScreener) и, если задан бесплатный `GMGN_API_KEY`, «умные деньги» и KOL из GMGN.
- Нет сделок — на экране демо (`/meme`, приложение) строка «❔ Почему пока нет сделок» с честной причиной:
  нет кошельков, кошельки ничего не купили, токены не прошли риск-фильтр (и какой именно пункт), пауза и т. п.
- Кнопки: «🧪 Демо: выключить/включить», «🔁 Демо заново» ($5/$10/$20 — то, чему бот научился, сохраняется),
  «💸 Продать (демо)», и «🧪 Купить на демо» в каждом сигнале копитрейдинга. Вручную: `/meme buy АДРЕС 2`.
- После 10 демо-сделок бот честно скажет, в плюсе ли демо и стоит ли подключать настоящий кошелёк.
- Когда кошелёк подключён и в нём есть SOL, торгует настоящий счёт; демо продолжает учиться молча. Не хватает SOL
  на сделку — бот предупредит, и сделку повторит демо.

### 🧠 Чему бот учится сам (кнопка «🧠 Чему научился»)

- **Стоп и тейк-профит.** Каждая копия без денег записывает путь цены. На этих путях бот проверяет соседние правила
  (стоп −20/−30/−40%, тейк-профит нет/+30/+50/+100%) и переходит на лучшее — от 15 копий, только если выигрыш ≥5%
  и только на один шаг. Новое правило сразу действует на демо и реальные сделки.
- **Реальные комиссии.** Перед каждой покупкой (демо и реальной) бот замеряет по Jupiter, сколько стоит вход+выход,
  и по медиане замеров пересчитывает стоимость копий — оценки кошельков становятся честнее.
- **Кого копировать.** По копиям 👀-кошельков (от 12) решает, окупаются ли они. Теряют — демо перестаёт их копировать,
  а настоящий счёт возвращается к «только ⭐».
- Каждое изменение приходит сообщением «🧠 Урок» с цифрами «было/стало бы».

**Честно про демо:** на демо нет промаха цены при реальном исполнении и задержки транзакции, поэтому живые сделки
обычно хуже на 1–3%. Правила подбираются по прошлому — будущее может отличаться.

**Подключение (5 минут, с телефона):**
1. Phantom → нажми на аккаунт слева вверху → «Добавить / подключить аккаунт» → «Создать новый аккаунт», назови «Бот».
2. Переведи на «Бот» немного SOL с основного аккаунта (для старта ~$5–10 — только то, что не жалко).
3. Phantom → Настройки → «Управление аккаунтами» → «Бот» → «Показать приватный ключ» → скопируй.
4. Render → сервис → **Environment** → `SOLANA_TRADER_KEY` = ключ → Save Changes (бот перезапустится).
5. В боте `/meme` — увидишь адрес и баланс. Нажми «🟢 Включить автокопирование» и подтверди.

⛔ Ключ — **только** в Render. Не присылай его в чат (бот удалит такое сообщение и предупредит), в ИИ или «поддержке».
Сид-фраза не нужна вообще. Основной кошелёк бот не трогает. Все сделки видны в Phantom → «Бот» и на Solscan.

**Как бот решает и чем защищён:**
- копирует только ⭐ — кошельки, чьи копии без денег уже дали прибыль (от 5 копий, с учётом опоздания и комиссий).
  Переключатель «⭐ + 👀 хорошие» добавляет кошельки в плюсе по своей истории (рискованнее);
- перед покупкой: риск-фильтр копитрейдинга + проверка «туда-обратно» через Jupiter. Нельзя продать — ловушка
  (honeypot), не покупает. Вход+выход дороже 6% — тоже нет;
- продаёт: кошелёк продал · стоп (по умолчанию −40%) и тейк-профит, которые бот подбирает сам, по котировке Jupiter · пул слили · 48 часов. Неудачную продажу повторяет
  каждые 30 секунд и пишет, как продать вручную;
- тормоза: сумма сделки $1/$2/$3/$5, до 2 позиций, запас 0,01 SOL на комиссии, дневной лимит убытка $2, пауза 12 ч
  после 3 убытков подряд;
- после продажи закрывает пустой счёт токена и возвращает залог ~0,002 SOL (иначе он съедал бы ~10% мелкой сделки).

Необязательно: бесплатный ключ Jupiter (developers.jup.ag/portal) → `JUPITER_API_KEY` (без него лимит 30 запросов
в минуту — хватает, но медленнее); бесплатный Helius → `SOLANA_RPC_URL`.

**Честно:** ⭐ появляются не сразу (от 5 копий у кошелька — обычно несколько дней), и до этого бот ничего не купит.
Мемкоины чаще всего падают, копия хуже оригинала, прошлые успехи ⭐ ничего не гарантируют. Ключ в Render видит
любой, у кого есть доступ к твоему аккаунту Render, — поэтому на «Боте» держи только небольшую сумму.

## 🎓 Учусь у трейдеров: YouTube и Twitch (`/mentors`)

Бот смотрит ролики крипто-трейдеров и читает чаты memecoin-стримеров. Ничего не берёт на веру: **каждый прогноз
проверяет ценой**.

- **YouTube.** Новые ролики выбранных каналов (RSS, без ключа) «смотрит» **Gemini** — ИИ Google открывает ролик
  по ссылке (звук и кадры, первые 20 минут). Из ролика бот берёт суть, прогнозы (монета, рост/падение, срок),
  советы и проверяет, есть ли реклама и хайп. Субтитры с сервера Render скачать нельзя (YouTube блокирует облачные
  серверы), а Gemini открывает ролик сам, поэтому блокировка ему не мешает.
- **Twitch.** Бот читает чаты анонимно, без ключей. Если стример, модератор или бот канала пишет адрес токена
  Solana, бот записывает цену в эту минуту. Записи прошедших эфиров (VOD) Gemini открыть не может, поэтому
  бот учится на живых чатах.
- **Проверка.** Мемкоин считается как настоящая копия: стоп, тейк-профит и комиссии, итог через 24 ч. Монета с
  Bybit/BingX считается по цене через срок прогноза минус комиссии. Результат усредняется с поправкой на везение.
  ⭐ получает тот, у кого от 8 проверок, в среднем от +2% и реклама не в каждом втором ролике: его прогнозы приходят
  сигналом, токены стримера — сделкой на 🧪 демо-счёте. 🔇 получает тот, у кого в среднем −3% и хуже: сигналов
  от него нет, а ИИ считает его мнение ненадёжным.
- **Советы с цифрами** («стоп −20%», «ликвидность от $50K», «не входить после +30%») бот проверяет на своей истории
  копий. Правило меняется, только если на истории совет дал бы хотя бы на 5% больше. Каждый совет получает пометку
  ✅ принят, ❌ не подтвердился или ⏳ мало данных.
- **ИИ** (`/ai` и вопросы в чат) видит выводы роликов, счёт каждого трейдера и настроение за неделю.

Управление: `/mentors` показывает список, счёт и кнопки. `/mentors add ссылка` добавляет канал YouTube или
twitch.tv/…, `/mentors video ссылка` разбирает один ролик. Можно просто прислать ссылку в чат. В приложении
есть карточка «🎓 Учусь у трейдеров».

**Ключ Gemini (бесплатно, 2 минуты):** aistudio.google.com/apikey → Create API key → Render → Environment →
`GEMINI_API_KEY`. Сайт Google AI Studio из России открывается через VPN, а бот на Render работает с ключом без VPN.
Если твой `AI_API_KEY` уже от Gemini (начинается с `AQ.` или `AIza`), отдельный ключ не нужен. Бесплатный лимит — 8 часов
YouTube-видео в день, бот тратит не больше 15 роликов × 20 минут. Без ключа бот разбирает ролики только по названию
и описанию.

**Gemini пишет «не подключён»?** Нажми в /mentors кнопку «🔌 Проверить Gemini» (или `/mentors gemini`): бот скажет,
нашёл ли ключ, в какой переменной и что ответил Google. С 2026 года AI Studio выдаёт ключи нового формата `AQ.Ab…`
(раньше были `AIza…`) — с версии 27 бот понимает оба и ходит в родной API Gemini (заголовок `x-goog-api-key`), потому
что ключи `AQ.` на OpenAI-совместимом адресе Google часто отклоняет. Пробелы, кавычки и перенос строки при вставке
с телефона бот убирает сам. Ключ кладётся только в Render → Environment, никогда не в чат и не в GitHub.

**Честно:** блогеры часто показывают токен, когда уже купили его сами, а реклама бирж и пресейлов встречается
постоянно. Поэтому за настоящие деньги бот «потому что сказал блогер» не покупает: только сигнал, демо и твоя
кнопка. Чтобы появились первые ⭐, нужно несколько дней проверок.

### 🏋️ Тренировка на демо (`/train`)

Всё, чему бот научился у трейдеров, он **сам проверяет сделками на виртуальных деньгах**:

- Каждый прогноз «вырастет» (монета с Bybit/BingX) и каждый токен, который стример показал в чате, — это идея для
  сделки. Бот открывает её по цене в момент прогноза.
- Одновременно торгуют **5 стратегий**, у каждой своё демо ($10, можно начать заново с $5/$10/$20): «Все прогнозы»,
  «Проверенные авторы» (⭐ или 3+ проверки в плюсе), «Согласие 2+ авторов», «Без рекламы и хайпа», «Уверенные
  прогнозы». Сделка — 25% счёта стратегии, не больше 4 открытых. Есть стоп, тейк-профит, комиссии и
  проскальзывание. Мемкоин держится до суток, монета — до недели (или до срока прогноза).
- **Чему учится сам.** (1) Выбирает лучшую стратегию: нужно от 8 сделок, средний результат считается с поправкой на
  везение. Только её идеи приходят сигналом «🏋️ Сигнал проверенной стратегии». Если все стратегии в минусе,
  сигналов нет. (2) Подбирает стоп и тейк-профит отдельно для монет и мемкоинов. Цену бот записывает весь срок идеи,
  даже после выхода, поэтому видно, что было бы при другом стопе. Правило меняется на один шаг и только если выгода
  от 5%.
- Кнопки: сделки, сигналы вкл/выкл, «писать о каждой сделке», пауза, «начать заново». Выученные правила при этом
  остаются. В приложении блок «🏋️ Тренировка на демо» находится в карточке «🎓 Учусь у трейдеров».

**Честно:** настоящие деньги тренировка не трогает. На демо нет реального проскальзывания, поэтому живые сделки
обычно хуже на 1–3%. Шорты не торгуются: на споте можно только купить.

### 🔭 Разведчик: бот сам ищет трейдеров (`/scout`)

Раз в сутки бот сам ищет новых крипто-трейдеров и **проверяет их не по словам, а по ценам**:

1. **Где ищет:** Gemini с поиском Google (если ключ Gemini задан), поиск каналов YouTube и стримы Twitch в категории Crypto. Ключи не нужны, кроме Gemini.
2. **Фейк-фильтр до испытания** (отсеянных бот больше не берёт):
   - миллион подписчиков, а смотрят сотни — похоже на накрутку;
   - казино, VIP-сигналы, пресейлы и раздачи в описаниях;
   - кликбейт «100x GUARANTEED», только Shorts, давно нет роликов, не про крипту;
   - на Twitch: слоты и гемблинг, почти нет зрителей.
3. **Испытательный срок** (🔭 в списке): YouTube 21 день, Twitch 10 дней, на испытании не больше 5 каналов YouTube и 5 Twitch. Ролики испытуемых бот смотрит только из **остатка** дневного лимита Gemini (последние 5 роликов дня остаются проверенным трейдерам).
4. **Итог испытания:**
   - ⭐ прогнозы окупились ценой (≥ 8 проверок, в среднем ≥ +2%) — остаётся;
   - 🔇 теряют, реклама в половине роликов, сплошной хайп, ни одного проверяемого прогноза — убирается;
   - срок вышел, а плюс не доказан — убирается; в плюсе, но проверок мало — ещё неделя.

**Прокачка v30:**
- 📜 **История прогнозов до испытания.** Бот берёт названия последних роликов канала («Bitcoin to 150K», «SOL crash»), достаёт из них прогнозы (через Gemini, а без него по словам) и проверяет на настоящих дневных свечах Bybit/BingX: вход — открытие следующего дня после ролика, выход — через 3 дня, минус комиссии. Если история в минусе — канал не берётся. Из прошедших берутся лучшие, а не первые попавшиеся. Историю каналов из списка бот пересчитывает раз в неделю (по одному каналу за раз), кнопка «📜 Проверить историю» — всех сразу.
- 🔗 **Снежный ком:** кандидаты из ссылок в описаниях ⭐ трейдеров.
- 🧠 **Самообучение поиска:** бот считает, какие источники и запросы YouTube дали ⭐, и ищет там чаще; Gemini получает список прошедших и отсеянных.
- 🏆 **Рейтинг** (`/scout rank`): сверху — в плюсе от 8 живых проверок, ниже — от 3, потом — только история, в самом низу — кто в минусе. Видно «если ставить по $10 на каждую идею».
- ⚡ **Ранний вылет:** сильно теряющих (в среднем ≤ −3% уже на 5 проверках) убирает, не дожидаясь конца испытания.
- ♻️ «Мягко» отсеянных (канал уснул, нет прогнозов) через 60–90 дней можно проверить снова; накрутка, казино и убыточные — навсегда.

Кнопки: `/mentors` → «🔭 Разведчик» (или `/scout`), «🔎 Найти трейдеров сейчас», «🏆 Рейтинг», «📜 Проверить историю», «⏸ Не искать самому». Свои каналы и стартовый список разведчик не трогает.

**Честно:** никто не знает заранее, кто из блогеров прибыльный, — число подписчиков об этом ничего не говорит. Поэтому разведчик **ничего не обещает при поиске**, а ⭐ даёт только проверка ценой. Ожидай, что из 10 найденных останутся 1–2, а иногда никто. Сделки по ⭐-идеям идут на демо (🏋️ Тренировка), реальные деньги — только через твои кнопки и лимиты.

## 🎥 Смотрю стримы вживую (`/stream`)

Бот не только читает чат Twitch, но и **смотрит сам эфир**: что стример делает на экране и что говорит.

* **Кто в эфире.** Раз в 2 минуты бот узнаёт, кто из Twitch-стримеров в 🎓 сейчас в эфире.
* **Взгляд на эфир.** Раз в 3/5/10/20 минут (выбираешь сам) и сразу, когда стример кидает адрес токена в чат,
  бот берёт последние 16 секунд эфира (видео со звуком, 720p, рекламные вставки пропускает).
* **Разбор.** Ролик смотрит Gemini и записывает **действия**: вход/выход, монета, цена входа, стоп, тейк, плечо,
  размер, что сказал. Бот помнит прошлый взгляд, поэтому видит действия во времени: передвинул стоп, усреднил
  убыток, закрыл в минус.
* **Плюсы и ошибки** по одному списку: ✅ ставит стоп, фиксирует прибыль, режет убыток, ждёт сетап, объясняет вход;
  ❌ нет стопа, усреднение убытка, большое плечо, FOMO, отыгрыш, отодвинул стоп, слишком большая позиция… Плюс
  дисциплина 0–10 и урок для новичка.
* **Проверка ценой.** Каждый увиденный вход бот проверяет по ценам Bybit/BingX/DexScreener (как прогнозы в 🎓)
  и запоминает, с какими ошибками он сделан. Со временем появляется **«цена ошибки»** на цифрах, например «входы без
  стопа: в среднем −6%». Входы ещё идут в 🏋️ тренировку на демо.
* **Итог эфира:** сделки, сильные стороны, ошибки, средняя дисциплина, уроки. Профиль привычек каждого стримера
  виден в `/stream` и в Mini App (🎓 → 🎥 Стримы вживую). ИИ-помощник тоже его видит.

Команды: `/stream` — кто в эфире и привычки; `/stream ник` — посмотреть эфир сразу (нового стримера добавит);
`/stream off|on`. (Команда `/live` занята: она включает реальную торговлю.)

**Честно об ограничениях.** Это не непрерывный просмотр. Бесплатный Gemini **Flash-Lite** даёт ~500 запросов в
день (у Flash всего 20, их тратят ролики YouTube). Бот берёт до 300 в день (`LIVE_PER_DAY`): 2 эфира раз в 5 минут —
это ~12 часов. От действия до сообщения проходит ~30–60 секунд. Цифры с экрана ИИ может прочитать неточно, поэтому
в счёт стримера идёт только проверка ценой. Если Twitch не отдал видео, бот смотрит превью-кадр эфира, но без
звука выводы слабее. YouTube-эфиры пока не смотрит: из облака YouTube часто требует вход. За настоящие деньги по
стримам бот не торгует. Нужен только тот же ключ `GEMINI_API_KEY`; ffmpeg ставится сам из `requirements.txt`.

### 🔎 Мелкие детали на экране и 🪞 повтор на демо (v34)

* **Мелкие детали.** Gemini смотрит эфир в **высоком разрешении и 2 кадра в секунду** (`LIVE_MEDIA_RES=high`,
  `LIVE_FPS=2`; если модель такое не умеет — бот сам откатывается к обычному режиму) и осматривает весь экран:
  углы, боковые панели, уведомления, второй монитор, телефон в кадре. Что ловит:
  🕵️ закрытый/инсайд-чат, 📣 колл-канал, 🎧 созвон, 👛 трекер кошельков (Cielo, GMGN, Axiom, Photon), 🐋 покупки
  KOL/умных кошельков, 🧑‍💻 действия разработчика, ⚡ ленту Axiom Pulse / GMGN, 🐦 твиты, 💰 рекламу.
  Цифры панели токена (капитализация, ликвидность, холдеры, топ-10, разработчик, снайперы, бандлы, инсайдеры)
  бот записывает и сам видит **красные флаги**: «вошёл, хотя топ-10 держат 62%» — это ошибка стримера.
* **Проверка токена.** Мелькнувший адрес бот сразу проверяет через GMGN (или RugCheck) и пишет цифры в сообщение.
  Новые ошибки: «входит по чужому коллу, не проверив токен», «входит, несмотря на красные флаги»; новый плюс —
  «проверяет холдеров, бандлы и разработчика».
* **Чего стоят «засветы».** Токены из инсайд-чатов, трекеров и сделок стримера уходят в ⚡ Пульс: он ведёт каждый
  сутки с теми же правилами и показывает, например, «токены из инсайд-чатов на экране: 23 шт., в среднем −41%».
* **🪞 Повтор на демо.** Вход, доливку, стоп и выход стримера бот сразу повторяет на виртуальных $10 по
  **настоящей** цене в момент, когда увидел (монета — цена Bybit/BingX, мемкоин — DexScreener), поэтому видна и
  цена опоздания. Два счёта: «🪞 точная копия» (всё как у стримера, даже без стопа) и «🧠 умная копия» (те же
  сделки, но без FOMO, входов без плана, красных флагов, доливок в минус и всегда со стопом). Счёт каждого стримера
  отдельно; вердикт «копировать или нет» — от 8 сделок. Плечо не повторяется, комиссии учтены, если стример ушёл из
  эфира — позицию закрывает стоп/тейк/срок (мемкоин сутки, монета 3 дня). Кнопка 🪞 в `/stream`, карточка в Mini App.

## ⚡ Пульс рынка: GMGN и Axiom Pulse (`/pulse`)

Бот сам смотрит рынок мемкоинов Solana, торгует кандидатами **на бумаге** и учится, какие признаки токена на самом
деле ведут к прибыли.

* **Откуда кандидаты** (раз в 3 минуты, цены — каждую минуту): **GMGN** — тренды за 5 минут, «окопы» (новые токены, почти завершившие
  bonding curve и только что вышедшие на DEX — ровно три колонки Pulse в Axiom: New Pairs, Final Stretch,
  Migrated), сделки умных кошельков и KOL, свежие коллы; **DexScreener** — что продвигают (работает и без ключа);
  **🎥 стримы** — токен мелькнул у стримера.
* **Что записывает:** цену и все признаки — ликвидность, капитализацию, возраст, холдеров, топ-10, долю
  разработчика (и продал ли он), снайперов, бандлы, инсайдеров, риск rug, wash-trading, число умных кошельков.
  Honeypot и пулы меньше $5k не берёт даже на бумагу. Каждого ведёт 24 часа; пул слили — считает −95%.
* **9 стратегий-фильтров** по $10 на бумаге (как пресеты Axiom/GMGN): все, безопасные, умные деньги, строгий,
  Final Stretch, Migrated, импульс, коллы и стримы, выученный фильтр. Стоп, тейк, комиссии и сеть Solana учтены.
* **Учится сам:** считает средний итог каждого признака (11 признаков × 3 корзины + источник), признаки с
  доказанным минусом (от 15 токенов) вносит в **стоп-лист** — на нём торгует «выученный фильтр»; стоп и тейк
  подбирает по путям цены (только если это лучше хотя бы на 1% за сделку, иначе это подгонка).
* **Сигналы** присылает только лучшая стратегия, и только если её плюс не похож на везение (от 10 сделок).
  Итог Пульса и повтора стримеров виден в 💰 `/profit` как отдельные способы (без денег).
* **Ключ GMGN** бесплатный и только читает рынок: gmgn.ai/ai → API key → Render → Environment → `GMGN_API_KEY`.
  Без ключа Пульс работает на DexScreener + RugCheck. Бот соблюдает лимиты GMGN (не чаще 2 запросов в секунду,
  на 429 честно ждёт, не повторяя) и ходит по IPv4 (по IPv6 GMGN отвечает «ключ неверный»).
* **Axiom:** открытого API у Axiom нет, а неофициальные библиотеки входят в аккаунт пользователя — так делать нельзя.
  Поэтому его Pulse бот повторяет через GMGN (данные те же, с блокчейна) и видит Axiom на экранах стримеров.

Честно: большинство мемкоинов падает. Пульс показывает на цифрах, что работает, а что нет. Настоящие деньги не трогает.

## 💡 Как заработать сейчас (`/earn`)

С $5 трейдинг даёт центы, а самый большой процент к депозиту часто дают **бесплатные акции биржи**.
Бот сам собирает их с официального API Bybit и показывает с честной пометкой, подходит ли это для $5:

- **🎁 Акции** — Launchpool (кладёшь USDT/MNT, каждый час капает новый токен, свои монеты забираешь), Token Splash,
  аирдропы, задания, бонусы Earn. Закончившиеся скрываются, сверху — то, что подходит для $5.
- **💰 Проценты** — лучшие ставки Bybit Earn по USDT, USDC, SOL и т.д. и сколько это в долларах с $5 в месяц.
- **🆕 Листинги** — новые монеты и **делистинги**: если биржа убирает монету, которая у тебя есть, бот пишет сразу,
  даже при выключенных уведомлениях (после делистинга продать будет нельзя или очень дёшево).
- **📰 Новости** — ForkLog и Cointelegraph, с монетами из заголовка.
- **🤖 План для моих $5** — ИИ смотрит твои балансы и текущие акции и пишет пошаговый план.
- **🔔 Уведомления** — бот проверяет раз в 15 минут и пишет о новых акциях (выключается кнопкой).

То же в приложении: карточка «💡 Как заработать сейчас» на главной. **Бот сам в акции не вкладывает**:
у ключа есть права только на спот-торговлю — участвовать нужно в приложении Bybit по кнопке «Открыть».
Деньги, положенные в Earn или Launchpool, не торгуются в режиме $5 — выбирай, что для тебя важнее.

## 📱 Приложение (Mini App)

Кнопка **App** слева от поля ввода в чате с ботом, команда `/app` или кнопка под `/start`.
Приложение открывается прямо в Telegram, ничего устанавливать не нужно.

| Вкладка | Что внутри |
|---|---|
| **Главная** | Баланс крупно и его график (реальный или демо), результат за сегодня, переключатель автоторговли, кнопки «Скан / Купить / Продать / Стоп», лучшие сигналы и последние сделки |
| **Рынок** | Свечной график любой пары (5м, 15м, 1ч, 4ч, 1д) с объёмами. Палец на графике показывает цену и время. Поиск монеты по бирже, покупка и продажа: по рынку или лимитом, быстрые суммы `$5 / $10 / 50% / всё` |
| **Сигналы** | Треугольники и межбиржевые связки карточками: шкала прибыли против порога автоторговли, безубыточность, плата за вывод, кнопка «⚡ Исполнить» |
| **Демо** | Все демо-счета: общий итог, кривые доходности каждого счёта в %, мини-графики, процент прибыльных сделок, причины отказов, история сделок, запуск со своими суммами |
| **Портфель** | Баланс на всех биржах и его история, кольцевая диаграмма по монетам, монеты по биржам (касание по монете открывает продажу), открытые ордера с отменой, график результатов циклов, журнал сделок |
| ✦ (кнопка справа) | ИИ-чат. Ответы, кнопки «применить настройку» и предпросмотр ордеров, если попросишь «купи BTC на 5$» |
| ⚙️ (вверху) | Тест / реальный режим, стоп-кран, лимиты риска, параметры поиска, состояние ключей бирж |

**Безопасность.** Каждый запрос приложения подписан Telegram. Сервер проверяет подпись токеном бота (HMAC-SHA256)
и пускает только ID из `ALLOWED_USER_IDS`. Торговать, менять режим и лимиты риска может только владелец.
Каждый ордер проходит через предпросмотр. Реальный режим включается двумя подтверждениями. Все лимиты из
раздела «Торговля» действуют и в приложении, а о реальных действиях бот дублирует сообщение в чат.

**Скорость.** Приложение весит около 30 КБ в сжатом виде и не тянет сторонних библиотек: графики рисуются
вручную на canvas. При повторном открытии экран сразу рисуется из кэша, а свежие данные подтягиваются за
доли секунды. Цена на вкладке «Рынок» обновляется каждые 5 секунд, остальное раз в 7 секунд, и только пока
приложение открыто. График баланса записывается сам раз в 15 минут и попадает в резервную копию.

> Нужен адрес с **https**. На Render он есть автоматически (`RENDER_EXTERNAL_URL`). На другом хостинге
> укажи `PUBLIC_URL=https://твой-адрес`. На компьютере без https приложение в Telegram не откроется,
> но можно посмотреть дизайн в браузере: `python scripts/webapp_preview.py` → http://localhost:8080/app
> (ненастоящие данные, без бирж и Telegram).

## 👻 Кошелёк Phantom

Phantom — это **твой личный кошелёк** (сеть Solana), а не биржа. Ключей API у него нет, и торговать им
бот не может: никакой бот не должен получать доступ к деньгам в личном кошельке. Что бот умеет:

* **Показывать баланс** (SOL, USDC, USDT, JUP, BONK и другие токены) с оценкой в $ по ценам бирж: в `/phantom`, `/balance`,
  в приложении на вкладке «Портфель» и в `/doctor`.
* Для этого нужен только **публичный адрес**: Phantom → «Получить» (Receive) → Solana → «Копировать».
  Пришли его командой `/phantom АДРЕС`, вставь в приложении (кнопка «Phantom» на главной) или
  добавь переменную `PHANTOM_ADDRESS` в Render.
* 🔒 **Сид-фразу (12 слов) и приватный ключ не отправляй никому и никуда.** Если по ошибке пришлёшь
  сид-фразу боту, он её не сохранит, попробует удалить сообщение и предупредит. Но в этом случае
  всё равно создай новый кошелёк и переведи туда деньги.
* Чтобы торговать монетами из Phantom: переведи их на Bybit или BingX (адрес пополнения на бирже, сеть Solana).
* Публичный узел Solana бесплатный, но с лимитами. Если появится «слишком много запросов», укажи свой
  `SOLANA_RPC_URL` (например бесплатный ключ Helius).

## ⚙️ Автоторговля: почему нет сделок (`/why`)

Автоторговля покупает треугольный цикл, только если он даёт **≥ 0.3% после комиссий по свежему стакану**
на сумму, которая реально есть на счёте. Если сделок нет, это почти всегда одна из причин ниже.
`/why`, кнопка «Почему нет сделок» в `/trade` и карточка «Автопилот» в приложении показывают, какая именно:

| Что пишет бот | Что сделать |
|---|---|
| ⛔ ключ «только чтение» | Биржа → API → изменить ключ → **Read-Write + Spot Trade** (без Withdraw), затем `/doctor` |
| мало денег на счёте | Биржи не берут ордера меньше ~$1–5 на шаг. Пополни **торговый** счёт (Unified/Spot) до $10–20 или оставь `/test` |
| нет циклов ≥ 0.3% | Это нормально: такие циклы редкие. Бот ждёт и не тратит деньги. Порог можно снизить: `/set auto_min 0.15` |
| дневной лимит | Сработала защита (`daily_loss`, `daily_trades`), завтра продолжит сама |

Раз в 6 часов бот присылает сводку (`/set auto_report 0`, чтобы отключить), а о новой проблеме пишет сразу.

## 🔥 Мемкоины: DexScreener, GMGN, Axiom, FOMO

Данные берутся из открытых API **DexScreener** (цены, ликвидность, объём, сделки) и **RugCheck** (риск скама).
Ключи не нужны. Что есть:

* `/dex название или адрес` и вкладка «Мемкоины» в приложении: карточка токена, красные флаги
  (мало ликвидности, токену меньше суток, покупки без продаж, «бумажная» капитализация), вердикт.
* Если по названию находится несколько токенов, бот показывает и их: **скамеры копируют тикеры**, проверяй адрес.
* `/hot`: тренды DexScreener. `/radar on`: бот раз в 10 минут присылает новые токены Solana,
  которые прошли фильтры (ликвидность ≥ $30K, объём ≥ $100K, RugCheck ≤ 30).
* Кнопки **GMGN**, **Axiom**, **DexScreener** открывают токен в этих терминалах.

Честно: у GMGN, Axiom и FOMO **нет официального API для торговли**, поэтому бот покупать там не может:
только анализ и ссылки, а сделку ты подтверждаешь сам в их приложении и своём кошельке.
Отсутствие флагов не означает «безопасно»: большинство новых мемкоинов теряют почти всю цену.
Заходи только суммой, которую не жалко потерять.

## Как это работает

```
каждые 60 с ─► все спотовые цены со всех бирж (один запрос на биржу)
            ├─► межбиржевой: для каждой монеты биржа, где купить дешевле, и биржа, где продать дороже
            ├─► треугольный: все циклы USDT → A → B → USDT на каждой бирже
            ─► вычитаем комиссии, отсекаем неликвид и подозрительно большие прибыли
            ─► лучшие варианты проверяем по реальным стаканам
            ─► демо-счета «торгуют», сигналы уходят в Telegram (с кнопкой «🤖 Разбор ИИ»)
каждый день ─► отчёт: сколько сканов, что нашли, как идут демо-счета + мнение ИИ
по запросу  ─► /analysis (математика комиссий) и /ai (ИИ получает все цифры и объясняет их)
```

## 🧪 Демо-счета: проверь на виртуальных деньгах

Перед тем как вкладывать реальные деньги, запусти демо. Бот сам «торгует» виртуальным балансом
**по реальным ценам бирж** и учитывает всё, что съест прибыль в жизни:

| Что учитывается | Как |
|---|---|
| Торговые комиссии | taker-комиссия обеих бирж из данных биржи |
| Глубина стакана | покупка и продажа идут по реальным заявкам, а не по одной «лучшей» цене |
| Минимальный ордер | сделка отклоняется, если баланс меньше минимума биржи |
| Комиссия за вывод | берётся с биржи, если та отдаёт её без ключа; иначе `DEMO_WITHDRAW_FEE_USD` (по умолчанию $0.5) |
| Закрытый ввод/вывод | связка отклоняется, если биржа сообщает, что ввод или вывод закрыт |
| Время перевода | продажа идёт по цене **через `DEMO_TRANSFER_MIN` минут** (по умолчанию 10), а не по цене сигнала |
| Где лежат деньги | после продажи на бирже B следующая покупка возможна только на бирже B |
| Сложный процент | каждая сделка идёт на весь баланс, прибыль реинвестируется |

**Треугольник моделируется так же честно.** Сначала бот находит цикл по тикерам и проверяет его по стаканам,
а потом **запрашивает стаканы заново** и исполняет сделку уже по ним. Между этими шагами проходит реальное
время сетевых запросов, как у живого бота. Если за это время возможность исчезла (так чаще всего и бывает),
демо честно запишет убыток. Один и тот же цикл на одном счёте повторяется не чаще раза в 10 минут,
чтобы не «съедать» одни и те же заявки в стакане много раз.

**В Telegram:**

```
/demo_start          6 счетов: $5, $50, $500 × межбиржевой и треугольный
/demo_start 5 20     свои суммы (до 5 штук)
/demo                сводка по всем счетам
/demo 5              подробно по $5: средняя сделка (ожидалось / вышло), причины отказов
/demo_history        последние сделки
/demo_stop           остановить
```

Состояние сохраняется в бэкапе в Telegram и переживает перезапуск.

### Честно про $5

Стартовать с $5 можно, но приготовься к тому, что **в межбиржевом арбитраже демо почти не будет совершать сделок**.
Посчитаем:

* спред между биржами после торговых комиссий обычно **0.5–2%**, то есть **$0.03–0.10** с $5;
* вывод монеты на другую биржу стоит в среднем **$0.1–1**, то есть **2–20%** от $5;
* многие биржи не принимают ордера меньше **$1–5**.

Итог: на $5 комиссия за вывод почти всегда больше прибыли. Демо-счёт это наглядно покажет в `/demo`,
в разделе «Почему связки отклонены», с примером лучшей отклонённой связки и расчётом.
Демо-счета на $5, $50 и $500 работают параллельно, так что через сутки в отчёте будет видно,
с какой суммы и на какой стратегии появляется результат. Это и будет проверенный ответ, без фейков.

**Треугольник и $5.** Здесь нет платы за вывод, поэтому $5 может пройти, если у всех трёх пар
минимальный ордер меньше $5. Но такие циклы живут доли секунды, и профессиональные боты с серверами
рядом с биржей забирают их первыми. Демо это учитывает (повторный запрос стаканов перед исполнением),
поэтому, если отчёт показывает плюс, это не фантазия. Если показывает ноль или минус, это тоже честный ответ.

Чего здесь нет и не будет: «гарантированной прибыли» и «проверенной стратегии x2 в неделю».
Тот, кто такое продаёт, зарабатывает на продаже, а не на торговле.

### 🛟 Gemini перегружен (503 «high demand») — v36

Иногда Google отвечает «This model is currently experiencing high demand» (ошибка 503). Это временная перегрузка
серверов Google, ключ и бот в порядке. Теперь бот:

* ждёт 3 секунды и повторяет; не помогло — берёт **другую модель Gemini** (для эфиров сначала другую Flash-Lite,
  и только если заняты все — обычный Flash), а перегруженную не трогает 10 минут;
* когда перегрузка проходит — **сам возвращается** к лучшей модели (чтобы не тратить маленький лимит Flash);
* если заняты все модели — пишет одну понятную строку вместо JSON и повторяет сам: эфир через ~1,5 минуты,
  ролик YouTube — позже (раньше ролик при такой ошибке пропускался навсегда);
* в чате с ИИ отвечает «серверы Google перегружены, спроси через минуту», а если подключён второй ИИ (Groq,
  OpenRouter) — сразу отвечает он;
* кнопка «🔌 Проверить Gemini» при перегрузке честно говорит: «ключ рабочий ✅, но серверы Google перегружены».

**Как это помогает:**
* **Не «ложится».** Один ИИ упёрся в лимит или перегружен — сразу отвечает следующий.
* **🧠 Консилиум** (`/council` или `/council свой вопрос`): бот задаёт один и тот же вопрос по своим данным до 7 разным ИИ
  **одновременно**. Каждый отвечает строго: ВЕРДИКТ (торговать / осторожно / ждать), уверенность, почему, идея, риск.
  Итог — по голосам с весом уверенности. Правила честности: «торговать» — только если ответили минимум 2 ИИ, за это
  ≥ 2/3 и никто уверенно не против; ничья — в пользу осторожности; ответил один — так и пишется.
* **Второе мнение перед сделкой.** ИИ-трейдер подготовил ордер → под ним кнопка «🧠 Второе мнение: консилиум ИИ».
* **♾ Автомат перед настоящими деньгами** (если подключено ≥ 2 ИИ) спрашивает консилиум. Большинство говорит «ждать» —
  деньги не включаются 12 часов, обучение без денег продолжается. Консилиум может только **запретить**, разрешить сверх
  правил (доказанный плюс, маленькие лимиты) — нет. ИИ недоступны — работают обычные правила.
* `/council keys` — какие ИИ уже подключены и какие ещё можно добавить бесплатно.

Честно: несколько ИИ не делают рынок предсказуемым. Консилиум снижает риск, что бот поверит одной модели, которая
ошиблась или выдумала цифры, — но это мнение, а не гарантия прибыли.

## 🔁 Переводы между биржами с анализом перед выводом и покупкой — v42

Бот сам переводит монеты между **твоими** Bybit и BingX. Адрес получателя он берёт через API второй биржи (твой адрес
пополнения) — вписать чужой адрес нельзя ни командой, ни в приложении, ни через ИИ.

**Анализ перед каждым выводом** (свежие данные бирж; перед нажатием «Перевести» — ещё раз):

| Проверка | Что ловит |
|---|---|
| ключи обеих бирж и право Withdraw | ключ без вывода, сломанный ключ |
| вывод монеты открыт на бирже-источнике, ввод — на бирже-получателе | блокировки вроде Terra, техработы, делистинг |
| общие сети, где открыто и то и другое; выбирается самая дешёвая | «вывод в сети, которой нет у второй биржи» |
| минимум вывода, комиссия (≤5% суммы, автобаланс ≤3%) | невыгодные переводы |
| свободный баланс с учётом комиссии (Bybit — и Funding) | «не хватает на комиссию» |
| адрес пополнения (и мемо) второй биржи | монеты без адреса/мемо |
| лимиты: $30 за раз, $100 в сутки (`/transfer limit 30 100`) | крупные ошибки |

После вывода бот следит: ушёл ли вывод, дошёл ли депозит, и сам переносит дошедшее с Funding на торговый счёт.
Пишет в чат на каждом шаге (и если перевод идёт дольше 6 часов).

**⚖️ Автобаланс** (выключен по умолчанию): если автоторговле на одной бирже не хватает USDT, а на другой лишние — бот
переводит недостающее (не чаще раза в 12 ч, только когда прошлый перевод дошёл).

**Анализ перед покупкой.** Автопилот (режим $5) не берёт монеты, вывод которых закрыт биржей; ИИ такую покупку не
предложит; в ручной заявке появится «⛔ купить можно, вывести нельзя». Межбиржевое демо и раньше пропускало закрытые монеты.

**Как включить (с телефона):**

Биржи дают вывод через API только ключам с белым списком IP. Бесплатный Render выходит в интернет с адресов из своих
диапазонов (Connect → Outbound показывает их как `…0/24`, то есть по 256 адресов), а BingX принимает только отдельные IP, до 20.
Поэтому нужен **отдельный ключ только для вывода**: если Render сменит IP, не пройдёт только перевод, а торговля продолжит работать.

1. `/transfer ip` — бот покажет IP, с которых реально выходит (раз в час проверяет и пишет «🌐 новый IP», если он сменился).
2. BingX → API → **новый ключ**: права только **Чтение + Withdraw**, в белый список IP вставь список из шага 1.
   Bybit — так же (новый ключ, Assets → Withdraw, IP из шага 1).
3. Render → Environment: `BINGX_WITHDRAW_API_KEY`, `BINGX_WITHDRAW_API_SECRET` (для Bybit — `BYBIT_WITHDRAW_API_KEY`,
   `BYBIT_WITHDRAW_API_SECRET`) → Save. Торговые ключи не трогай.
4. **Адресная книга** (главная защита): на бирже-источнике добавь адрес пополнения второй биржи (бот покажет его в
   проверке) и включи «только адреса из списка».
5. `/transfer test` (или кнопка «🧪 Проверить вывод» в `/transfer` и в Mini App) — проверка в обе стороны **без перевода
   денег**: ключ вывода и IP, открыта ли монета, сеть и комиссия, адрес пополнения, есть ли он в адресной книге Bybit
   (и не «новый ли», с запретом на 24 ч), сколько можно вывести, сколько заморожено, и пробная сумма, которая пройдёт анализ.
6. В боте: `/transfer` → **🔓 Разрешить переводы** (два подтверждения, только главный владелец).
7. `/transfer USDT 5 bingx bybit` → анализ → **✅ Перевести**. В Mini App: Кошелёк → **🔁 Перевод между биржами**.

`/stop` снимает разрешение на переводы. Ключ вывода — 4 необязательные переменные из шага 3.

## ⚖️ Спред-арбитраж между биржами (`/spread`) — v43

Одна и та же монета на Bybit и BingX стоит чуть по-разному. Бот каждую минуту сравнивает все общие монеты и, если
на одной бирже монета дешевле настолько, что после **всех** комиссий остаётся прибыль, — покупает её там, переводит
на вторую биржу и продаёт там.

**Перед покупкой** (если что-то не так — не покупает):

| Проверка | Зачем |
|---|---|
| вывод монеты на бирже покупки и ввод на бирже продажи открыты | блокировки вроде Terra, техработы сетей, делистинг |
| общая открытая сеть, её комиссия и минимум вывода | комиссия вывода считается в прибыли |
| сеть быстрая (≤ 15 мин: APT, SUI, SOL, TRC20, BEP20, TON, XRP…) | пока монеты едут, цена может уйти |
| стаканы обеих бирж на твою сумму, минимальные ордера | «красивая» цена в тикере бывает на $1 |
| одна ли это монета (контракт; огромный спред без подтверждения — отказ) | у бирж бывают разные токены с одним тикером |
| прибыль после покупки, вывода и продажи ≥ 1% и ≥ $0.03 (`/spread min 1.5`) | иначе комиссии съедят всё |
| адрес второй биржи в адресной книге (Bybit проверяется через API) | без этого биржа не выпустит вывод |

**После покупки:** вывод на адрес пополнения второй биржи (адрес бот берёт сам) → ждёт зачисления → продаёт.
Если вывод не прошёл — продаёт монеты обратно на той же бирже (теряются только комиссии). Если пока ехали цена
упала — ждёт безубытка до 2 ч, но при просадке 3% продаёт сразу. Одна сделка за раз.

**Режим.** По умолчанию — 🧪 тест на бумаге: настоящие стаканы, комиссии и время перевода, деньги не двигаются
(даже если остальной бот торгует по-настоящему). Реальные сделки: `/live` + разрешённые переводы (`/transfer`) +
`/spread real` с подтверждением. Стоп-кран `/stop` выключает спред и возвращает его в тест.

**Подготовка (один раз):** `/spread addr` покажет адреса пополнения, которые нужно добавить в адресные книги
(для EVM-сетей — как «универсальный адрес»). Если выгодный спред упрётся только в книгу, бот пришлёт точный адрес.

**Честно:** на $5 сделок будет мало. Комиссия вывода монеты обычно $0.05–0.5 — это 1–10% от $5, а Bybit и BingX —
крупные биржи с почти одинаковыми ценами. Большие спреды чаще всего там, где биржа закрыла ввод или вывод (бот это
видит и не лезет). Тест на бумаге покажет реальную картину до того, как рисковать деньгами.

## 🌌 Космический интерфейс, центр управления и штурман-ИИ — v41

**Приложение (кнопка «Открыть» в боте) полностью перерисовано в космическом стиле** — и на телефоне, и на компьютере.

* **♾ Центр управления** на главной: кольцо **здоровья бота 0–100**, что работает само (движки с зелёными огоньками),
  сколько за сутки было сделок / находок мемкоинов / починок / проблем, следующий шаг и живая лента. Одна кнопка —
  включить или выключить полный автомат.
* **🩺 Здоровье** (нажми на кольцо): циклы бота, ключи бирж, ИИ, вторая копия бота, память, самообновление — у каждого
  пункта подсказка, как починить. То же в Telegram: `/autonomy` → строка «🩺 Здоровье».
* **📡 Лента событий** — всё, что бот сделал сам: сделки, киты, решения ИИ, починки сторожа. Фильтры «Сделки / Мемкоины /
  Автомат / Проблемы». Пишется, даже если уведомления выключены, хранит последние 60 событий и не пропадает при перезапуске.
  В Telegram: `/feed`.
* **🧠 Штурман-ИИ** на главной: три строки «Сейчас → Риск → Шаг» по настоящим данным бота, плюс кнопки быстрых вопросов
  («Почему нет сделок?», «Где плюс?», «Оцени риск»). Ответ хранится 20 минут, чтобы не тратить бесплатные лимиты ИИ.
  Штурман также дописывает свой комментарий к «Результату» автомата в Telegram. ИИ ничего не меняет сам: только объясняет.
* **🌙 Тихие часы 23:00–08:00** (по желанию, каждому своё: `/notify` или в Ленте): ночью обычные события копятся и утром
  приходят одним сообщением «Пока ты спал». **Деньги, предупреждения и проблемы приходят сразу всегда.**
  Отложенное хранится в памяти: если Render перезапустит бота ночью, оно останется только в Ленте.
* **💻 На компьютере** — две колонки, боковое меню слева, окна по центру экрана.

**Больше сделок (без лишнего риска).** Автопилот (режим $5) раньше проверял только 13 монет из списка. Теперь он
добавляет к ним самые ликвидные пары биржи прямо сейчас (оборот от $30 млн за сутки, спред до 0,15%, без стейблкоинов и
токенов с плечом), всего до 20 монет. Порог качества стратегии прежний, поэтому сделок больше только за счёт новых
кандидатов. Прибыль это не гарантирует.

**Быстрее и меньше ошибок.**
* Приложение опрашивает сервер каждые 7 секунд. Если ничего не поменялось, сервер отвечает «без изменений» (ETag/304)
  и экран не перерисовывается: примерно 34 КБ → 0 на каждом таком опросе, меньше расход батареи и трафика.
* Звёзды и анимации сделаны на чистом CSS, без canvas и тяжёлых скриптов. Если в системе включено «Уменьшить движение»,
  анимации выключаются.
* При обрыве связи запрос повторяется сам, а сверху появляется плашка «Нет связи». Ошибки JavaScript попадают в лог
  Render (не больше 30 в час), чтобы было видно, что нужно чинить.

## 🔔 Уведомления всем пользователям — v40

Раньше всё, что бот присылает сам, шло только главному владельцу. Теперь уведомления получают **все пользователи бота**:

Что приходит всем: сделки автомата и режима $5, мемкоины и копитрейдинг, пульс рынка, эфиры и разборы трейдеров,
решения ♾ автомата и 🧠 консилиума, проблемы с ключами бирж, «две копии бота», новые версии и ежедневный отчёт.

* **Видно, кто что сделал.** Если друг включил реальный режим, исполнил сделку, нажал `/stop` или что-то поменял в

## 🩺 Кнопка проверки и самые умные бесплатные ИИ — v39

**Проверка** — кнопка «🩺 Проверить всё» в `/start`, команда `/doctor` или «Проверка» в приложении. Теперь проверяет:

* **Биржи и ключи** — как раньше: доступ с сервера, права и срок ключей, деньги на счёте Funding.
* **Каждый ИИ вживую.** Бот одновременно задаёт всем подключённым ИИ короткий вопрос и пишет по каждому: ✅ ответил за
  N секунд и какой моделью, или ❌ что не так и что сделать («скопируй ключ заново → Render → `OLLAMA_API_KEY`»,
  «лимит на сегодня исчерпан», «сервис не отвечает»). ИИ, который сейчас на паузе из-за лимита, не трогаем — проверка
  не съедает лимит. Итог: «отвечают 4 из 5, 🧠 консилиум готов». Плюс какие ИИ ещё можно добавить бесплатно.
* **Полный автомат** — включён ли, разрешены ли деньги, сколько учебных движков работает, не уснул ли сервис.
* **Источники данных** — ключ GMGN, кошелёк мемкоинов, Gemini для видео.
* **Сервис** — приложение, резервная копия, версия, память.

Под результатом кнопки: «🔄 Проверить всё ещё раз», «🤖 Только ИИ» (то же — `/doctor ai`), «➕ Добавить бесплатные ИИ».

**Новые бесплатные ИИ, все без телефона** (вход через почту или Google):

| ИИ | Самая умная бесплатная модель | Лимит | Переменная в Render |
|---|---|---|---|
| Ollama Cloud | **DeepSeek V4 Pro**, Kimi, Qwen 3.5 | недельный, по одному вопросу за раз | `OLLAMA_API_KEY` |
| SambaNova | **DeepSeek V3.2** / V3.1 | 20 вопросов в день на модель | `SAMBANOVA_API_KEY` |
| Z.ai | GLM-4.7-Flash | бесплатно навсегда | `ZAI_API_KEY` |
| Cloudflare AI | Qwen 3.8, GPT-OSS 120B | 10 000 «нейронов» в день | `CLOUDFLARE_API_TOKEN` + `CLOUDFLARE_ACCOUNT_ID` |

Ещё: OpenRouter и LLM7 теперь сначала берут **бесплатный DeepSeek**. Консилиум спрашивает до **7** ИИ сразу. Если модель
оказалась только для подписчиков, бот сам переходит на бесплатную. У Z.ai и Cloudflare бот берёт **только** модели
из бесплатного списка — платную случайно не выберет.

Официальный API DeepSeek платный (нужна зарубежная карта), поэтому DeepSeek бесплатно — через Ollama Cloud, SambaNova,
OpenRouter и LLM7. Честно: бесплатные лимиты у сервисов меняются; если какой-то закроют, проверка это покажет, а бот
будет спрашивать остальные ИИ.

## 👥 Пользователи бота (`/users`) — v37

Можно пустить в бота друга **без его Telegram ID**:
1. `/users` → **➕ Пригласить** — бот даст ссылку вида `t.me/<бот>?start=inv_…`.
2. Отправь её другу. Он открывает ссылку → **Запустить** → сразу получает доступ. Тебе придёт сообщение, кто вошёл.
3. Ссылка **одноразовая** и живёт **24 часа**. Передумал — `/users` → «🚫 Отменить все ссылки».
4. Убрать человека: `/users` → «➖ Убрать …» → подтвердить. Он сразу теряет доступ.

⚠️ **Приглашённый получает полный доступ, как у владельца**: сигналы, ИИ, настройки, демо, Mini App и
**настоящая торговля твоими деньгами** на Bybit/BingX и в кошельке бота (с теми же подтверждениями и лимитами).
Ключи бирж он не видит (они только в Render). 🔁 Переводы между биржами он может проверять и запускать (только на
твою вторую биржу, в пределах лимитов), но разрешать их и менять лимиты — только главный владелец. Добавлять и убирать людей может только
главный владелец (первый ID в `ALLOWED_USER_IDS`). Отчёты и бэкапы по-прежнему приходят только владельцу.
Список хранится в настройках и в резервной копии — переживает перезапуски Render.

**Т-Инвестиции убраны** (v37) по просьбе владельца: команда `/tinvest`, экран в приложении и токен больше не нужны.
Переменную `TINVEST_TOKEN` в Render можно удалить.
